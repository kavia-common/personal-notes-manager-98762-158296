# Notes Android App (Light, Modern Minimalistic)

This Android app lets you create, edit, delete, view, and search personal notes. It uses a local SQLite database for persistence and follows a light, modern minimalistic design with Material Components.

Features:
- Create note
- Edit note
- Delete note
- View list of notes
- View note details
- Search notes

Theme colors (as requested):
- Primary: #1976D2
- Secondary: #424242
- Accent: #FFC107

Build and Run:
- Build: ./gradlew :app:build
- Install Debug: ./gradlew :app:installDebug
- Launch the app named "Notes" on the device.

Configuration:
- No environment variables are required. See .env.example for future configuration guidance.
